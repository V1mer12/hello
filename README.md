# My BIBLIA 0.3

Особистий десктопний застосунок для навчання, розвитку, системного планування та заробітку.

## Що вже реалізовано

- темний графітовий інтерфейс;
- панель навігації з секціями: Сьогодні, Навчання, Заробіток, Ресурси, Колесо, Щоденник;
- локальне зберігання даних у `%APPDATA%\MyBIBLIA\workspace.json`;
- автоматичне резервне копіювання перед зміною формату даних;
- базовий каркас для OpenAI API без зберігання ключів у коді;
- Electron-структура для локального запуску на Windows.

## Розділи застосунку

- Сьогодні — фокус дня, задачі та пріоритети.
- Навчання — мови, розклад, self-testing, активне пригадування, повторення та журнал помилок.
- Заробіток — арбітраж трафіку, програмування, продукти та інші канали доходу.
- Ресурси — підбірка ресурсів, курсів та посилань.
- Колесо — життєве колесо та ключові сфери.
- Щоденник — нотатки, рефлексія та щоденна система.

## Англійська A0

Вміст для навчання вже підготовлений у стилі:
- 5 основних слів;
- до кожного слова 3 прості чанки;
- український переклад;
- структура для повторення та журналу помилок.

## Локальний запуск

### 1) Встановити залежності

```bash
npm install
```

### 2) Запустити в режимі розробки

Windows PowerShell:
```powershell
npm run dev:win
```

Windows CMD:
```cmd
npm run dev:win
```

Або просто:
```bash
npm run dev
```

### 3) Запуск звичайної версії

```bash
npm start
```

## Зберігання даних

Основний файл:

```text
%APPDATA%\MyBIBLIA\workspace.json
```

Перед зміною формату даних робиться резервна копія у папці:

```text
%APPDATA%\MyBIBLIA\
```

Наприклад:

```text
workspace.backup-2026-10-27T15-00-00.json
```

## OpenAI та ключі

Ключі не зберігаються у коді. Для локальної розробки використовуйте змінні середовища:

- MYBIBLIA_OPENAI_KEY
- OPENAI_API_KEY

Приклад для Windows PowerShell:

```powershell
$env:MYBIBLIA_OPENAI_KEY="your_key_here"
npm run dev:win
```
