# My BIBLIA 0.3

Особистий десктопний застосунок для навчання, розвитку, системного планування та заробітку.

## Розділи

- Сьогодні
- Навчання
- Заробіток
- Ресурси
- Колесо
- Щоденник

## Тема інтерфейсу

- Темний графітовий стиль
- Чорні, сірі, сині відтінки
- Мінімалістичний, зосереджений на концентрації

## Де зберігаються дані

Дані зберігаються в системній папці:

%APPDATA%\MyBIBLIA\workspace.json

Перед будь-якою зміною формату даних автоматично створюється резервна копія.

## Як запускати

1. Встановіть залежності:
   npm install
2. Запустіть у режимі розробки:
   npm run dev
3. Або стандартний запуск:
   npm start

## Параметри OpenAI

Ключ OpenAI не записується в код. Для локальної розробки використовують змінні середовища:

- MYBIBLIA_OPENAI_KEY
- OPENAI_API_KEY

## Структура проєкту

- resources/app/main.js — головний процес Electron
- resources/app/preload.js — безпечний bridge між main/render
- resources/app/index.html — розмітка вікна
- resources/app/styles.css — стилі графітової теми
- resources/app/app.js — логіка інтерфейсу та відображення секцій

## Примітка

Проєкт зберігає сумісність із попереднім прогресом у файлі workspace.json і створює backup перед змінами структури даних.
